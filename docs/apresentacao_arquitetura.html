Construtor Visual de Fluxos (Estilo n8n)

Crie qualquer jornada de atendimento apenas arrastando blocos pelo navegador.

  • ✓
    Zero Código Necessário: O usuário cria etapas, perguntas, mensagens automáticas e desvios diretamente no Canvas interativo.
  • ✓
    Nós Inteligentes: Blocos condicionais (Ex.: "Se o usuário mencionar ameaça física ➡️ Desvia imediatamente para o Trilho de Proteção").
  • ✓
    Publicação Instantânea: Alterou no Canvas? A próxima mensagem enviada no WhatsApp já segue a nova rota na hora, sem reiniciar servidor.
👶 Explicando de forma simples:
É como brincar de Lego ou dominó. Você encaixa as pecinhas dizendo: "Primeiro dá 'Oi', depois pergunta o bairro, depois descobre o problema e encaminha para a unidade certa".
📚

RAG Inteligente (Base de Conhecimento Sem Perdas)

Como a IA lê leis, decretos, tabelas e manuais sem alucinar e sem cortar frases.

1. Chunking com IA

Em vez de cortar o texto a cada 500 letras (o que quebra frases e regras no meio), a própria IA entende parágrafos, tabelas e tópicos inteiros antes de fatiar.

2. Intent Query Rewriter

Se o cidadão manda um áudio confuso: "preciso de cumida pra minhas cria", o reescritor traduz para a busca: "Requisitos para Cesta de Alimentos e Benefício Eventual de Vulnerabilidade".

3. Reranking Semântico

Pega as 10 páginas encontradas e reordena com nota de 0 a 100, entregando para o bot apenas a informação exata e verificada.

👶 Explicando de forma simples:
É como uma biblioteca mágica. Você não precisa ler 500 páginas de um livro de leis. Você joga o PDF lá dentro, e a IA vira um especialista naquele livro que responde exatamente onde ir e o que levar.
🧪

MLOps & Treinamento Visual de Modelos

Machine Learning profissional configurável pelo navegador.

  • ✓
    Modelos Locais Leves & Rápidos: Treinamento de classificadores de texto rápidos (TF-IDF + Random Forest / Naive Bayes) que rodam em 2 milissegundos sem gastar API paga.
  • ✓
    Benchmark Lado a Lado: O painel permite testar a mesma frase na LLM (Gemini/OpenAI) e no Modelo Local ao mesmo tempo para ver quem acerta mais.
  • ✓
    Aprendizado Contínuo com Casos Reais: Casos atendidos pelos assistentes viram automaticamente dados de retreinamento para a IA ficar cada vez mais afiada.
🤝

Copiloto de Onboarding para Usuários Leigos

Um assistente que cria fluxos e prompts conversando com o usuário.

Nem todo gestor ou atendente sabe configurar um fluxo de nós ou escrever prompts de sistema complexos. O Copiloto Integrado conversa em linguagem natural:

Usuário: "Quero criar um atendimento para o CRAS que primeiro pergunte se tem idoso na casa e depois veja se precisa de BPC."

Copiloto: "Perfeito! Criei o nó de pergunta 'Pessoa Idosa', adicionei a regra condicional de desvio e já pluguei na base de dados do BPC. Deseja aplicar?"

📂

Data & Knowledge Hub (Central de Documentos & Datasets)

Controle transparente de arquivos, chunks semânticos, vetorização e curadoria de dados de Machine Learning.

📄 Ingestão & Edição de Chunks

Upload de PDFs de leis e decretos com visualização lado a lado. Se uma regra municipal mudar, o administrador edita o texto do chunk diretamente na tela e o sistema re-vetoriza no mesmo segundo.

🏷️ Curadoria de Dados de Treino (MLOps)

Gestor de frases rotuladas (Frase ➔ Intenção). Permite alimentar o modelo local com novas gírias e expressões regionais ou importar planilhas CSV com centenas de exemplos históricos.

💡 Em Resumo:
Nada de "caixa preta" ou scripts manuais de Python para mexer em dados. O usuário tem um estúdio visual completo para inspecionar, editar e reindexar qualquer conhecimento do sistema.
